design-brain

A ledger of the design decisions you keep re-teaching AI. Sources are harvested into a queue of candidates with their evidence; you promote the ones you stand behind; the confirmed set compiles into three agent skills that load on every project. Compiled skills never name a past project.

QueueSwipe or use ← → to retire and promote, ↓ to skip, Z to undo, N to note. RulesThe whole ledger: confirmed, in review, retired, conflicts. Select rows for bulk verdicts. SourcesEvery published reference the ledger cites, grouped by publisher. SkillsWhat compiled into each skill; compile with C and install the symlinks. TabsQ, R, O, S.
