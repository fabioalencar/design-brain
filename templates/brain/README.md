# My design brain

A private ledger of design decisions, reviewed with `design-brain review` and compiled
into agent skills with `design-brain compile`. Created by
[design-brain](https://github.com/fabioalencar/design-brain).

- `sources.yaml` — the projects this brain learns from, with scope
- `inbox/` — candidates awaiting a verdict (starts with the reference seed pack)
- `decisions/` — what you confirmed
- `patterns/` — named, quotable things to detect or keep
- `inventory/` — facts per project, generated
- `skills/`, `exports/` — generated from decisions; never hand-edit

Keep this repository private: candidates quote your own words and may name clients.
