## Rule

Progress toward a goal is shown as distance remaining, and any progress the user has already earned is credited up front. The last steps are made short so completion accelerates.

## Why

Motivation rises as the end nears; a visible, shrinking remainder keeps people going where an abstract task does not.

## Examples

- A progress bar that starts partially filled because sign-up already counted.
- A loyalty card with the first stamp given.

## Exceptions

Fake or inflated progress is a manipulative pattern; only credit real work.
