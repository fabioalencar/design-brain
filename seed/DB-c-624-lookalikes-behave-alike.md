## Rule

Visual sameness (colour, shape, size, type) is reserved for elements with the same function.

- links look like links everywhere
- things that are not clickable do not borrow the link style
- two different actions do not share one appearance

## Why

Users infer function from appearance; a lookalike that behaves differently breaks the inference.

## Examples

- All external links underlined in the same colour; headings never coloured like links.
- Icon buttons with identical shape and size across a toolbar.

## Exceptions

None known.
