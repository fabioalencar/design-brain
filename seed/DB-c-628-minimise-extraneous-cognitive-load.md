## Rule

Every element on a screen is checked for the mental work it demands: reading, comparing, remembering, decoding.

Anything that adds load without adding to the task is removed, deferred, or converted into a default.

## Why

Working memory is small; load spent on the interface is load taken from the task, and overload shows up as errors and abandonment.

## Examples

- A wizard that hides steps until they apply instead of showing all fields greyed out.
- Numbers formatted with units and separators so the user does not parse them.

## Exceptions

Intrinsic load of a hard task is legitimate; the target is the extraneous part.
