## Rule

Emphasis is scarce: a single element per view is allowed to break the pattern (colour, size, weight).

If several things are highlighted, nothing is.

## Why

An item that differs from its neighbours is what gets remembered; competing highlights cancel each other.

## Examples

- One filled primary button among outlined secondaries.
- The recommended pricing tier visually distinct; the others identical.

## Exceptions

Emphasis must not rely on colour alone, so that colour-blind users also see the difference.
