## Rule

Documentation exists, is findable from the screen it describes, and is written as short task steps rather than a feature tour.

In-context hints appear at the moment of need; a full reference is one click away.

## Why

Users reach for help only when stuck; help they cannot find or cannot skim does not exist for them.

## Examples

- A "?" next to a complex field opening a two-line explanation with a link to the full article.
- Empty states that explain how to create the first item.

## Exceptions

Simple consumer flows should need no help at all; if they do, fix the flow first.
