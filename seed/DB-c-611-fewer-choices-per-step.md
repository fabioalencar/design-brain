## Rule

Each screen or menu presents the few options relevant to the moment.

When many are needed, group them, stage them, or recommend a default so the user decides among a handful, not dozens.

## Why

Decision time grows with the number and complexity of options; long undifferentiated lists slow everyone and stall some.

## Examples

- Onboarding that asks one question per step instead of a ten-field form.
- A menu that shows the six common actions and puts the rest under "More".

## Exceptions

Expert users scanning a known list (a file list, a contact list) are not slowed by length; do not paginate those artificially.
